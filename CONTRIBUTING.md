# Contributing

Report a reproducible problem with the instructions, helper tools or rubric through a GitHub issue. Include the operating system, runtime version, command and redacted output. Do not include tokens, personal records, databases, private code or participant submissions.

During the event, build on `submission/<team-id>` in your team fork and open a submission PR to organizer `main` by 22:00 CET. Freeze source/tests and record the full commit at 21:55. Do not push solutions directly to organizer branches or merge submission PRs. Follow [the submission workflow](docs/08-Submission-Workflow.md); a facilitator-receipted checksummed snapshot is the offline fallback, not the normal delivery route. Follow the event code of conduct and investigate only the supplied fixture artifact with its owner's agreement.

Tool changes need meaningful positive and failure-path tests. Event rule changes must be announced to all teams before scoring. Do not add prizes, sponsorship claims or product entitlements without organizer authorization.
